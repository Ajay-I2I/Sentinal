🎯 7 QUICK STEPS

STEP 1: GO TO VERCEL (1 min)
  → https://vercel.com
  → Sign in with GitHub
  → You see Dashboard

STEP 2: IMPORT REPO (2 min)
  → Click "Add New" → "Project"
  → Paste: https://github.com/Ajay-I2I/Sentinal
  → Click "Import"

STEP 3: CONFIGURE (2 min)
  Framework: Next.js ✓
  Build: npm run build ✓
  Output: .next ✓
  Install: npm install --legacy-peer-deps ✓
  Root: sentinel-ai ✓
  → Click "Continue"

STEP 4: ADD ENV VARS (3 min)
  Add these 6 variables:
  
  1. OPENROUTER_API_KEY = sk-or-v1-YOUR-KEY
  2. OPENROUTER_MODEL = nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free
  3. API_TIMEOUT_MS = 15000
  4. RESPONSE_WORD_LIMIT = 40
  5. NEXT_PUBLIC_APP_URL = (leave empty)
  6. NEXT_PUBLIC_ENABLE_VOICE = false

STEP 5: DEPLOY (1 min)
  → Click "Deploy" button
  → WAIT 3-5 minutes

STEP 6: GET URL (1 min)
  → See "Deployment Complete"
  → Click "Visit"
  → SAVE YOUR URL: https://sentinal-XXX.vercel.app

STEP 7: TEST (2 min)
  → Create profile
  → Send message
  → Say "I'm drinking"
  → See real name + emergency numbers
  → No "User A"? ✓ SUCCESS!

⚡ QUICK FIXES

NO RESPONSE FROM AI?
  → Check OPENROUTER_API_KEY is correct
  → Wait 10 seconds, try again
  → Check browser console (F12)
  → See "Error"? Go to Vercel Logs

"USER A" IN RESPONSE?
  → Refresh page
  → Clear profile data
  → Create NEW profile with real name
  → Try again

PAGE BLANK/WHITE?
  → Press F12
  → Check Console tab
  → Copy error message
  → Check Vercel build logs
  → Redeploy

BUILD FAILED?
  → Go to Vercel "Deployments"
  → Click failed deployment
  → Click "Logs"
  → Search for "error"
  → Fix env vars
  → Click "Redeploy"
